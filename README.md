# 課題管理アプリ

このアプリは、大学生向けに課題の締切を管理し、通知で忘れないようにするためのアプリです。  
科目ごとに課題を整理し、カレンダーや検索機能で簡単に確認できます。

## 主な機能
- 課題の追加・編集・削除
- 締切日の管理
- 通知機能（通知タイミングの設定）
- 詳細リマインダー機能
- 課題の完了・未完了切り替え
- 科目名での検索
- カレンダー表示
- 毎週繰り返し課題の設定

## 使い方
1. アプリを起動します。
2. 「＋」ボタンから課題を追加します。
3. 課題名・科目・締切を入力します。
4. 必要に応じて通知タイミングを設定します。
5. カレンダー画面で締切を確認します。
