# 課題管理アプリ

Flutterで開発した、学生向けの課題管理アプリです。  
課題の締切、科目、メモ、通知、カレンダー表示、毎週繰り返し課題を管理できます。

## 作成背景

大学の課題が複数科目で重なり、締切や優先順位を把握しづらいと感じたため、
自分が日常的に使える課題管理アプリを開発しました。

## 主な機能

- 課題の追加・編集・削除
- 締切日・締切時間の登録
- 科目とメモの管理
- SQLiteによるローカル保存
- 課題一覧の検索
- カレンダー表示
- カレンダーからの課題編集
- 毎週繰り返し課題の管理
- 締切1日前のローカル通知
- 期限切れ・今日まで・明日までの表示
- 完了済みタスクの管理

## 工夫した点

### 毎週繰り返し課題の表示制御

毎週繰り返し課題は、将来分のタスクを自動生成するようにしました。  
一方で、タスクリストに将来分がすべて表示されると見づらくなるため、
タスクリストには現在確認すべき課題のみを表示し、カレンダーには将来分も表示されるようにしました。

### カレンダーと一覧の役割分担

タスクリストでは、直近で取り組むべき課題を確認できるようにし、
カレンダーでは、今後の課題予定を日付ごとに確認できるようにしました。  
これにより、日々の作業確認と長期的な予定確認の両方に対応できるようにしました。

### 締切状態の分かりやすい表示

単に締切日を表示するだけでなく、
「今日まで」「明日まで」「○日遅れ」のように状態が分かる表示にしました。  
また、締切が近い課題や期限切れの課題はカードの色を変え、優先度を視覚的に把握しやすくしました。

### ローカル通知の実装

`flutter_local_notifications` と `timezone` を使い、
締切1日前に通知が届くようにしました。  
課題の編集や削除に合わせて通知も更新・キャンセルできるようにし、
古い通知が残らないように意識しました。

## 苦労した点

SQLiteのテーブル設計とマイグレーションに苦労しました。  
開発途中で毎週繰り返し課題用のカラムを追加したため、
既存DBに対して新しいカラムを追加する処理が必要になりました。  
`onUpgrade` を使ってDBのバージョンを管理し、既存データを残したまま機能追加できるようにしました。

また、毎週繰り返し課題では、親タスクと自動生成された子タスクの扱いに注意しました。  
タスクリストとカレンダーで表示条件を分けることで、見やすさと予定管理のしやすさを両立しました。
